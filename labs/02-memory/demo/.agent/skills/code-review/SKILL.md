# Code Review

按这个顺序看，每一项有问题就写一条，没有就跳过：

1. **会不会算错**：边界值（空列表、0、负数）有没有处理；
2. **会不会看不懂**：函数名能不能说清它做什么，有没有超过 30 行的函数；
3. **会不会难改**：有没有同一段逻辑复制了好几份。

输出格式：

```text
[严重程度] 文件:行号  问题一句话
            建议怎么改
```

严重程度只用三档：`必须改`、`建议改`、`可以不改`。没有问题就直接说“没发现问题”，不要为了凑数硬找。
